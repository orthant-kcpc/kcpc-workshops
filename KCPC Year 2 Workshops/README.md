# kcpc-workshops

All workshops hosted by KCPC (across 2026 - 2027.

## Year 2 Workshops

Year 2 workshops are structured using the following pairing model:

* **Week 1** = Theory
* **Week 2** = Application

Accordingly, each workshop pairing should use the following folder structure:

```text
W1/
  Slides/
    Week [X] Slides.tex
  Papers/
    Week [X] Papers.tex
  Reading/
    Week [X] Reading.tex
  Week [X] Slides.pdf
  Week [X] Papers.pdf
  Week [X] Reading.pdf

W2/
  Slides/
    Week [X] Slides.tex
  Problems/
    Week [X] Problems.tex
  Solutions/
    Week [X] Solutions.tex
  Week [X] Slides.pdf
  Week [X] Problems.pdf
  Week [X] Solutions.pdf
```

Where **Week 1** is focused primarily on theoretical material, **Week 2** is focused primarily on application and problem solving.

### Week 2

The **Slides** should provide a brief introduction to the workshop before presenting the problems selected by the workshop leaders for discussion. Each problem covered in the slides should be accompanied by its corresponding solution, allowing workshop leaders to introduce the problem and work through the solution during the session.

The **Solutions** folder should contain solutions for **all** problems in the workshop, including problems that are not covered during the session.
