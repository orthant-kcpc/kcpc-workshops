# External Competitive Programming Resources

A curated collection of resources to support KCPC workshops and independent practice.

## Contests and Practice

- **[AtCoder](https://atcoder.jp/)**: Regular contests with very good problems (mostly mathematical). AtCoder Beginner Contest and AtCoder Regular Contests are a very good starting point. Check out [Kenkoooo](https://kenkoooo.com/atcoder/#/table/) for all of the problems on AtCoder.
    - **[AtCoder Educational DP Contest](https://atcoder.jp/contests/dp/tasks)**: A focused set of dynamic programming problems, ranging from introductory recurrences to more advanced techniques.
- **[Codeforces](https://codeforces.com/)**: Frequent rated contests, a large [problem archive](https://codeforces.com/problemset) filterable by difficulty and topic, editorials, and community discussions.
- **[USACO](https://usaco.org/)**: The USA Computing Olympiad, with past contests and solutions across Bronze, Silver, Gold, and Platinum divisions. Useful for practising longer, algorithm-focused problems.
- **[CSES Problem Set](https://cses.fi/problemset/)**: A topic-organised collection covering core techniques such as sorting, dynamic programming, graphs, range queries, and mathematics.
- **[Kattis](https://open.kattis.com/)**: An extensive problem archive, including many ICPC-style problems. Useful for individual practice and team contest preparation.

## Learning and Reference

- **[CP-Algorithms](https://cp-algorithms.com/)**: Detailed explanations of algorithms and data structures, with correctness arguments, complexity analysis, and C++ implementations. Particularly useful as a reference when learning a new technique.
- **[USACO Guide](https://usaco.guide/)**: A free, structured curriculum with explanations, curated practice problems, and solutions. Useful for competitive programmers generally, even if you are not preparing for USACO.
- **[Competitive Programmer's Handbook](https://cses.fi/book/book.pdf)**: A free book by Antti Laaksonen covering competitive programming fundamentals, algorithms, and data structures, with C++ examples.
- **[Codeforces EDU](https://codeforces.com/edu/courses)**: Structured courses with lessons and practice problems, including the ITMO Academy course on common algorithms and data structures.
- **[KACTL](https://github.com/kth-competitive-programming/kactl)**: KTH's compact ICPC team reference library. Useful for studying concise implementations and building a contest reference once you understand the underlying algorithms.

## Videos and Walkthroughs

- **[SecondThread](https://www.youtube.com/channel/UCXbCohpE9IoVQUD2Ifg1d1g)**: Competitive programming videos, contest solution discussions, and live problem-solving streams. Useful for seeing how an experienced contestant approaches problems.
