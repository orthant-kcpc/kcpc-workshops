# kcpc-workshops

All workshops hosted by KCPC (whether collaborative or not) across 2025 - 2027

## Standard Workshops

All workshops made solely by KCPC are supposed to have the following folder structure: 

```
slides/
  Week [X] Slides.tex
problems/
  Week [X] Problems.tex
solutions/
  Week [X] Solutions.tex
reading/
  Week [X] Reading.tex
papers/
  Week [X] Papers.tex
Week [X] Slides.pdf
Week [X] Problems.pdf
Week [X] Solutions.pdf
Week [X] Reading.pdf
Week [X] Papers.pdf
```

Where Typst is used instead of Latex, please consider the same folder layout!
